# 首页布局

该app存在一个页面,页面四周以淡紫色预览创建的遮罩层(在后台,遮罩层是透明的),遮罩层屏幕中心显示设置参数

# 功能介绍

该App能够通过无障碍权限,在手机屏幕四周顶层创建一个透明的遮罩层,该遮罩层为触摸无效区域,能够有效防止横屏打游戏时,手指误触四周边框,导致的屏幕跳屏问题

该App存在三种不同的防误触遮罩层,覆盖大部分误触场景,用户可以自由对这三种遮罩层进行高度的设置,可以通过状态栏的磁块自由控制开启和关闭,当屏幕遮罩层挡住无法操作时,映射音量+键,长按退出遮罩层

# 参数及作用

模式:下拉选项,可选择"模式一""模式二""混合"

* 模式一:在屏幕四周创建矩形遮罩层,通过顶部底部左侧右侧参数控制,矩形遮罩层的高度

* 模式二:在双手握手机大拇指放置区域,屏幕左下角和右下角创建扇形遮罩层,通过拇指范围参数控制扇形遮罩层的大小

* 混合:将模式一和模式二的遮罩层区域一起创建

顶部:边距拖动条,通过拖动条控制顶部遮罩层的高度范围为0~15%的屏幕范围

底部:边距拖动条,通过拖动条控制底部遮罩层的高度范围为0~15%的屏幕范围

左侧:边距拖动条,通过拖动条控制左侧遮罩层的高度范围为0~15%的屏幕范围

右侧:边距拖动条,通过拖动条控制右侧遮罩层的高度范围为0~15%的屏幕范围

拇指范围:边距拖动条,通过拖动条控制双手大拇指放置区域,屏幕左右两侧扇形遮罩层的范围,0~30%的屏幕范围

启动开关:当打开启动开关后,屏幕遮罩层生效,应用退至后台
